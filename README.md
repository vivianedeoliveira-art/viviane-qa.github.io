# Portfólio — Viviane De Oliveira

Portfólio profissional estático para publicação no GitHub Pages.

## Publicar

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde a publicação.

## Personalização antes de publicar

No `index.html`, substitua:
- o link do LinkedIn pelo seu perfil;
- o link do GitHub pelo seu perfil;
- `seu-email@exemplo.com` pelo seu e-mail profissional.

O conteúdo foi estruturado para posicionamento de QA Sênior, destacando testes manuais, automação, APIs, web/mobile, qualidade orientada a risco, colaboração e evolução em IA.
